---
title: Selene
description: Hermetic Selene Lua linter
---

Selene provides correctness-oriented linting for the repository's
hand-maintained Lua files. The repository standard-library description permits
the intentional `al` configuration DSL and Neovim's `vim` global while keeping
Selene's ordinary Lua diagnostics enabled.
