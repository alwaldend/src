# Optional reference comparison record

For complex or stalled work, keep a concise record in task output. Use only
views and measurements that are available and useful to the decision.

| Reference or frame | What it controls | Candidate view | Difference or uncertainty |
| ------------------ | ---------------- | -------------- | ------------------------- |
|                    |                  |                |                           |

For each important iteration, record the largest mismatch, the change tried,
its visible effect, and any regression. If a measurement helps, state its unit,
tolerance, and perspective uncertainty. An overlay is meaningful only when
its framing is sufficiently aligned for the comparison being made.

Record whether the result meets the user's stated criteria, and report material
remaining differences. Do not invent a fixed numeric acceptance threshold or
require a reference view that was not supplied.
