## Why

Component-specific AppRoles should be maintained with the infrastructure
that uses them.

## What Changes

Direct new AppRoles to the owning component while retaining Vault
administrative authentication and a dedicated backend.

## Capabilities

### New Capabilities

- `component-local-approles`: Ownership guidance for new infrastructure AppRoles.

### Modified Capabilities

None.

## Impact

Updates the infrastructure skill and its evaluation guidance.
