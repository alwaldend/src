# Historical project-agents delta

These requirements describe the archived change at its recorded acceptance point. They were imported without applying them to the current `project-agents` baseline. Current source and baseline requirements own present behavior.

## ADDED Requirements

### Requirement: Measured friction baseline

Representative task archetypes MUST retain bounded FrictionRecord evidence with stable defect signatures and measured avoidable cost before optimizations are selected.

#### Scenario: A recurring workflow defect is investigated

- **WHEN** the baseline samples a representative task archetype
- **THEN** the evidence names the defect, avoidable reads or commands, observed latency, and measurement limits

### Requirement: Evidence-backed optimization lifecycle

Each adopted ergonomics improvement MUST link measured baseline, predeclared threshold, reviewed learning proposal, owner-local change, regression, fallback, and retirement rule.

#### Scenario: An improvement is retained

- **WHEN** a proposed optimization passes its evidence and regression gates
- **THEN** the maintained change remains traceable and its retirement condition stays explicit
