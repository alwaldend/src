# Repository Blender evaluations

This suite records the generic operational boundary for Blender work in this
repository: pinned Bazel execution, background-versus-foreground selection,
task-owned outputs, source preservation, deliverable verification, and
composition with specialist visual workflows. It also covers the narrow,
explicitly requested Flatpak exception: a disposable live MCP mutation host
that never replaces pinned batch verification, including the required launch
and identity-reprobe fallback when no listener is already running. The
authoring-method case
requires analytical generation for genuinely exact or repeated structure but
rejects it as a universal default when direct visual control better fits an
organic reference-driven form.

The offline Bazel target validates the Promptfoo configuration, cases, and
staged skill without making a model call. A live behavioral target is omitted
because representative cases require Blender, Bazel, writable `.blend`
fixtures, GUI/MCP state for interactive operators, and image inspection.
Configuration validation does not prove those runtime behaviors or artistic
quality.
