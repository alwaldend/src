Each project has a landing page at `/projects/<name>/`. A project with
user-facing documentation publishes it under `/projects/<name>/docs/`, with a
`type: docs` cascade on its section index so it renders with the documentation
layout. Repository reference documentation, including project READMEs, lives
under [documentation](/docs/).
