## Design

Use one layout for the Projects and Infra indexes. The Infra index reads the
published infrastructure documentation sections for its entries, with links
to the existing documentation pages. The homepage uses the same entry
selection and creation-date order for both indexes.

Keep the existing flat panel styling and arrange its four sections in a
responsive grid. Site and External occupy the first row when there is room for
two columns. Apply the Projects and Infra link row styling to all sections.
Retain visible destinations and put the destination beneath each link title on
small screens. Link External entries to the Alwaldend namespace pages on
GitHub, GitLab, Docker Hub, and Hugging Face.
