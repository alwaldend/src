## ADDED Requirements

### Requirement: Shared header monogram

The site SHALL display its canonical S8 monogram beside the site name in the
shared header, with a visible appearance in light and dark themes.

#### Scenario: Read a page with the header logo enabled

- **WHEN** a visitor opens the homepage, projects index, or project documentation index
- **THEN** the shared header displays the S8 monogram beside the site name
- **AND** the icon remains visible in light and dark themes
