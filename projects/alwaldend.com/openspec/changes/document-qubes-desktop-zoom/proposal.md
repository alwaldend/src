## Why

Accidental Xfce desktop zoom can make Qubes OS difficult to use. The Qubes
OS notes should explain how to restore normal magnification.

## What Changes

- Document Alt and downward scrolling over the desktop or taskbar.
- Explain that upward scrolling with Alt increases desktop magnification.

## Capabilities

No capability changes; this is documentation of existing behavior.

## Impact

Only the Qubes OS documentation and this change record are affected.
