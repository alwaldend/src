## Why

The site currently combines a purple accent with tinted Bootstrap surfaces.
The requested design uses a flat, minimalist monochrome interface throughout
the shared site theme.

## What Changes

- Use neutral light and dark palettes for navigation, content, and controls.
- Remove decorative shadows and use subtle borders and comfortable spacing.
- Preserve readable links, visible keyboard focus, and responsive navigation.

## Capabilities

### New Capabilities

### Modified Capabilities

- `project-alwaldend-com`: Specify a shared flat monochrome presentation.

## Impact

The owning Hugo SCSS extension points and home quick-link presentation change.
The existing Docsy dependency and site content remain the source of behavior.
Validation covers the rendered homepage, projects, blog, and documentation in
both color modes and at desktop and mobile widths. Deployment is separate.
