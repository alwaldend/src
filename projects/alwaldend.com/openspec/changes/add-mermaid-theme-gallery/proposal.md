## Why

The flat site theme needs a representative gallery to assess readability,
particularly connectors at documentation display sizes. Concrete comparisons
should inform improvements without changing the shared appearance prematurely.

## What Changes

- Add flowchart, sequence, state, class, entity-relationship, and mindmap
  samples, rendered through the current site theme in both color modes.
- Package a documentation gallery and link it from the owning README.
- Record measured observations and several restrained theme proposals, with
  isolated rendered comparisons where useful.

## Capabilities

### New Capabilities

None. This is documentation and evaluation of existing rendering behavior.

### Modified Capabilities

None. Shared theme changes remain proposals; `skip_specs: true` applies.

## Impact

Site-owned documentation and Bazel packaging. No shared theme changes, new
dependencies, historical diagram changes, or live deployment.
