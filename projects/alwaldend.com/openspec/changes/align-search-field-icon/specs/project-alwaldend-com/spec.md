## ADDED Requirements

### Requirement: Search field icon spacing

The site SHALL reserve space inside offline search fields for the search
icon. Placeholder and entered text SHALL have a visible gap from the icon,
including while the field has focus.

#### Scenario: Enter a search query

- **WHEN** a visitor focuses the search field and types
- **THEN** the icon and query text remain visually separated
- **AND** the placeholder and query text start at the same position
