A text-only Android launcher built with Kotlin and Jetpack Compose. It lets
you hide apps and runs without ads, tracking, or internet access.

## Links

- Source code: https://github.com/alwaldend/src/tree/master/projects/android_launcher

## Features

- Android app
- Kotlin, Jetpack Compose
- Only text
- FOSS, no ads, no internet access, no tracking, minimal dependencies
- Allows you to hide apps
