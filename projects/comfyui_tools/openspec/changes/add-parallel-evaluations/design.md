## Decisions

Proceed with a Go command using existing dependencies and the Vast SDK for ephemeral lifecycles. Terraform does not manage evaluation resources or state. Reuse the existing startup template through its pinned template renderer; avoid a second hardening script. Keep the normal rental and its state independent.

Bound parallelism, price and lifetime in configuration. Allocate only after local input validation and provisioning compilation. Each worker proceeds independently when ready and downloads before deletion. A cancellation-independent cleanup context handles ordinary failure and interruption. Reconcile ambiguous creation by exact unique labels, never by retrying the rental blindly. Serialize controllers sharing a namespace; worker instances within one controller run in parallel.

Persist a non-secret journal before creation. Labels carry a fixed eval namespace, run and job. The final sweep and standalone cleanup destroy every instance in the exact configured evaluation label namespace, regardless of age or run. Ordinary rental labels are outside that scope. Use one active controller per namespace; explicit manual cleanup intentionally terminates matching test instances. Deletion failures remain visible and retryable; never report success until confirmed absent. The operator chooses a standalone infrastructure cleanup target and an always-run final sweep, with no separate supervised service. Forced termination can skip the final sweep; the standalone target can recover all matching interrupted runs.

Record operational measures automatically. Artistic quality, requested subject, reference adherence and natural motion use an explicit review rubric; do not manufacture automatic quality scores or treat media validity as artistic acceptance.
