## Why

Manual rentals make model comparisons slow and waste capacity between independent tests. Reusable eval cases and a bounded lifecycle runner should collect comparable results and release each rental promptly.

## What Changes

- Add a reusable configurable parallel evaluation command in this project.
- Include the operator-approved thorn-landscape and plush-petting GIF cases and reference assets.
- Reuse the existing native workflows, approved model profiles, Vast SDK, startup template and authenticated ComfyUI CLI.
- Preserve exact inputs, seeds, timing, media checks and a human quality rubric with each result.

## Capabilities

### New Capabilities

- `image-generation-evaluations`: reusable cases, workload execution, result collection and independent ephemeral lifecycles.

### Modified Capabilities

None.

## Impact

Executable code, cases and references belong here. Deployment composition, credentials and run configuration belong to infra/image_gen/evals. Add no external software dependency and rent no capacity during source validation.
