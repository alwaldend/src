## Why

The H3 Video profile needs workflows that operators can open with the correct
weight files and starting settings already selected.

## What Changes

- Generate native H3 Base text-to-video and first/last-frame workflows.

## Capabilities

### New Capabilities

- `minimax-h3-video-workflows` provides ready-to-use native H3 Base graphs.

### Modified Capabilities

None.

## Impact

Bazel publishes both workflow files to the existing application installer.
