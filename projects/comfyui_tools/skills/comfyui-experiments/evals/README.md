# Coverage

The offline target validates configuration, cases and staged skill discovery.
It makes no model calls and does not prove agent behavior. The command E2E
target exercises queue continuity, original media, duplicate exclusions,
interruption, locking, acknowledgment loss, native error envelopes and
reconciled ownership-scoped cancellation. The skill cases cover finite ready
directions, evaluation before successors, retired branches, independent forks,
persistent pauses and the user's chosen result display surface.

No online Promptfoo target is provided: representative behavior requires an
authenticated mutable ComfyUI queue, task-specific producers and visual review.
Those surfaces cannot be safely reproduced by a read-only prompt evaluation.
The cases record expected routing and reasoning for a future controlled agent
evaluation; artistic quality and live utilization remain outside offline proof.
