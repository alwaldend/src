Autoscroll turns mouse movement into scrolling. Move the pointer and the
page scrolls horizontally or vertically, with configurable buttons, speed, and
a configuration that reloads without restarting.

## Features

- Horizontal and vertical scrolling driven by mouse movement
- Configurable buttons and scroll speed
- Configuration changes applied without a restart
- Python and PyQt6 command-line application
