An Android collector that reads the browser address bar through Android
accessibility services and sends visited URLs to an ActivityWatch server, so
browser activity appears alongside the rest of your tracked time.

## Features

- Reads supported browsers through accessibility, with no browser extension
- Sends browser URLs to a configured ActivityWatch server
- Written in Kotlin for Android
