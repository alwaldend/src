This tree contains first-party products and reusable project code. All tracked
content follows the repository's public-source policy.

Each project owns its specifications and maintained changes in
`<project>/openspec/`. Use the [pinned OpenSpec workflow](../tools/openspec/README.md)
with that project selected. [`infra/src/`](../infra/src/README.md) owns repository evolution.

## Requirements

- Bazel targets MAY use public visibility when their owner intends external
  reuse.
- Project artifacts MAY be published through an explicit release workflow.
- Project targets MAY be used by production build targets.

## Project status

Each direct project README declares exactly one `statuses` value from
[`statuses.yaml`](https://github.com/alwaldend/src/blob/master/projects/statuses.yaml).
The README owns the declaration. The definitions, index statuses, and existing
landing-page status fields are generated by
`bazel run //tools/repo_quality:inventory_update`; the inventory freshness check
rejects invalid declarations and stale projections. Edit the README before
running the updater. Keep release readiness and known limitations in project
prose; lifecycle alone does not establish build health or deployment state.

| Status        | Meaning                                                                                                                    |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `active`      | Substantive feature development is currently underway. Unfinished plans or routine upkeep alone do not qualify.            |
| `archived`    | Retained for reference; no further development or maintenance is intended.                                                 |
| `completed`   | The intended scope is declared complete. This does not promise ongoing maintenance, compatibility, or a published release. |
| `maintenance` | Retained with upkeep as needed and no current feature development. Scope may still be unfinished or limited.               |
