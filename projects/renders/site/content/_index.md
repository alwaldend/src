This project owns reusable 3D render assets together with the reference
images that control their likeness and the acceptance evidence bound to exact
candidate bytes.

## Features

- Reusable render assets with controlling references
- Acceptance evidence bound to exact candidate bytes
- Visual, structural, and animation gates before delivery
