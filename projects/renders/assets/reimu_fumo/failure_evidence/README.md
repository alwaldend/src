# Rejected representation evidence

This compact archive makes the terminal pixels behind the successor goal's
representation resets visible on a fresh checkout. Every image is rejected
evidence; none is a visual baseline, a retained module, or an acceptance pass.

`manifest.json` binds each image to its byte count, digest, attempt, candidate
digest, and representation family. Candidate `.blend` bytes are intentionally
not published because their recovered ancestors contain local path metadata.
The manifest therefore marks these historical renders as not independently
reproducible. They support inspection of the recorded negative knowledge, not
positive acceptance or exact render provenance.

Original recovered PNG ancillary metadata was removed while preserving the
pixel data. The exact unsanitized candidates and source renders remain only in
the ignored `out/reimu_fumo_finish/` recovery workspace.
