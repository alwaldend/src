# A87 result — preserve the S04 constructed front-hair module

A87 closes as **refine** with one exact provisional survivor: S04. It is not
the standalone untextured sculpt and does not satisfy the full-goal approval
gate. It is a reusable three-piece module to carry into the next isolated
coupon.

S00–S02 failed because the front owner combined a crown cap and fringe into a
uniform inflated dome while the two side locks collapsed into capsules. S03
proved that shallow thickness and held fabric edges could remove the tubular
read. S04 then separated ownership correctly: a short constructed forehead /
fringe panel terminates at an upper root seam for a future crown cap, while two
thin tapered cheek locks overlap behind it. Independent review preserves this
representation as the first A87 state compatible with constructed Fumo hair.

S05–S07 remain diagnostic only. Narrowing the central wedge was locally safe,
but applying S02 image-space lock translations literally made the locks detach
and then become long anime strands. The close gate therefore rejects S07 and
selects S04 exactly. This is an important bigger-picture correction: a module
landmark measured without its future crown, face, and garment context is not
automatically an executable transform.

## Honest acceptance state

No full-goal criterion passes yet. A87 makes bounded progress toward reference
likeness and plush construction, but crown/rear hair, face, bow, body,
garments, materials, rigging, final technical checks, and repository delivery
remain unverified. The next attempt must copy S04 exactly and add only a
separately owned crown/rear hair cap whose seams cover the intentional exposed
crown without recreating a helmet.

## Process audit

The fast loop itself is now adequate: live MCP edits take seconds and each
pinned three-view packet takes about 18 seconds. The dominant delay was not
compute; it was conflating component ownership, then treating a context-free
measurement as a direct modeling instruction. The successful reset was to
render an intentionally incomplete module and judge its interfaces, not force
one object to look complete. Future attempts should state pixel ownership and
occlusion dependencies before geometry, run a front/three-quarter contact gate
after the first state, and preserve a passing module instead of rebuilding it.
