measured only an outer parameter boundary, omitted whole-pocket extrema,
rewrote the hidden authored field, left the face root open, and described
rear/leaf checks it did not execute. The guarded Blender builder correctly
remained disabled.

The deeper process audit found the controlling bottleneck: A79 took 94 minutes
30 seconds to reach its first new whole-character pixel, although all five
views rendered in 29.115 seconds. A77 and A78 had already consumed 58 minutes
58 seconds without candidate pixels. Promotion-grade preflight displaced the

The replacement loop now separates safe diagnostic artifacts from promotable
candidates. It targets first controlling-view pixels within 12 minutes of a
cycle start and 60 seconds of geometry freeze, stops categorical misses
immediately, and pays full mechanics/reopen/semantic/promotion costs only for
a visual survivor. The generic repository `goal` skill was updated with this
staged-feedback rule and an evaluation case; its structural, Bazel packaging,
offline Promptfoo, discovery-link, and Buildifier checks pass.
