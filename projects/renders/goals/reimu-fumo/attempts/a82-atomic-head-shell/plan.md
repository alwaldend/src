# A82 atomic head-and-hair shell

## Decision

Reject a visual hull as visible, deforming, donor, or shrink-wrap geometry.
A52 and A79 already show that the uncalibrated turntable and occluded brown
union produce a structural uncertainty band and conflicting antipodal widths;
using that hull would generate another helmet. Keep the registered masks only
as per-view rejection evidence.

Genuine pointer-driven Sculpt Mode is also unavailable: the Blender MCP has no
pointer events, the live Blender window is not exposed through XWayland, and a
read-only X11 probe found no targetable Blender surface. Do not build a desktop
input service and do not retry scripted sculpt strokes.

Use the smallest remaining direct method: one closed, low-resolution cage
edited as one visible head-and-hair union in a disposable whole-plush copy.
This changes the A81 interface: there is no separate beige support, brown cap,
yoke, or analytic receiver. The cage is brown everywhere until its macro form
survives pixels; beige becomes a flush same-mesh material region only later.

## Bounded work

1. Make one isolated task copy of exact rung 003 and open only that copy in
   the existing foreground Blender.
2. Create one closed brown cage. Use direct Edit Mode changes to broad vertex
   selections; no generated receiver family, visual hull, curves, metaballs,
   cloth solve, scripted sculpt stroke, separate hair cards, or detail work.
3. Shape only the outer union: slightly flattened asymmetric crown, broad
   front, non-concentric depth, lower rear weight, irregular nape, and a broad
   return silhouette. Do not globally smooth it into an egg.
4. Freeze the file and immediately render exact front plus the weaker direct
   three-quarter through the existing repository-pinned batch renderer. Never
   render in the foreground Blender.

The all-brown C0 pair is only an implementation kill test; it cannot satisfy
the goal or earn relative quality credit. It survives only if both views show
a plausible non-helmet outer union, complete coverage, correct bounds, and a
clear improvement over the rung-003 macro distribution. A helmet, egg,
rounded box, vertical rear wall, periodic lower edge, narrow appendage, or
wrong scale stops A82 immediately without added parts.

Only a surviving C0 earns one C1 edit tranche: assign the canonical beige face
opening as a flush material region on the same mesh, preserve visible eyes and
the asymmetric brown framing, and render the same pair. A bald crown/temple,
raised plaque, duplicate rim, lost eye framing, or C0 silhouette regression
stops A82. Only a clean C1 pair earns the other three fixed views and later
constructed-panel extraction.

## Timing and review

Start the authoring clock with the first A82 geometry edit. Freeze C0 by
`T+10:45` and complete the pinned pair by `T+12:00`. Record author start,
snapshot, first pixel, pair, and decision timestamps. The generic renderer and
spec are invariant scaffolding and may be prepared before the clock.

Run one implementation-independent reviewer on the immutable pixels. The
reviewer sees references, rung 003, the stable defect ledger, and the images,
not the cage implementation. The coordinator alone updates the goal or any
canonical asset. A missed time gate or categorical pixel veto ends the work
unit; late pixels may be archived but may not authorize repair.
