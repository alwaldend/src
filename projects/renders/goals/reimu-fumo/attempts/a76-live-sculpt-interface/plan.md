## Process reset

A69--A75 show that deterministic batch generation and honest review are fast,
but analytic receivers, shells, cards, and visible patches remain generic.
A71's background synthetic sculpt probe moved too few vertices to support an
artistic edit. This attempt does not assume sculpting will work: it tests the
materially different live Blender MCP path, which has a real `VIEW_3D` context,
viewport screenshots, active selection, and native interactive operators.

## Primary decision review

The strongest objection is that the live MCP may expose the same ineffective
synthetic `brush_stroke` operator under a different transport, wasting another
cycle. The discriminating response is a tiny disposable interface gate before
any artistic claim. A single broad low-frequency stroke must produce a broad,
continuous, measurable support region and a visible viewport change while
preserving the parent. If it cannot, close A76 immediately.

The 226-vertex face retopology is deferred because it cannot change the
dominant hair shell. Automatic component visual hulls fail preflight under
occlusion. More scripted panels repeat A70/A74. A working live native sculpt
interface is therefore the smallest remaining strategy that could change
form directly instead of encoding another guessed formula.

## Exact scope

1. Use Blender MCP only against the connected live Blender instance.
2. Verify the live Blender version and current file before mutation.
3. Open the exact protected rung, immediately save a disposable copy under
   `out/reimu_fumo_attempt_076_live_sculpt/`, and verify the parent hash remains
   unchanged.
4. Duplicate one task-owned sculpt coupon from the relevant head/hair object;
   never sculpt the source object or tracked asset.
5. Run one broad native sculpt stroke through a confirmed `VIEW_3D` context.
6. Save the coupon once, capture before/after viewport evidence and quantitative
   displacement, then reopen/render it under pinned Blender 5.2.1 if the live
   interface gate passes.

## Interface pass gate

- The intended target object is active, selected, visible, single-user, and in
  Sculpt mode; the live area is explicitly `VIEW_3D`.
- At least 8% of coupon vertices move more than `0.10 mm` and at least 1% move
  more than `0.50 mm`, with one connected broad support rather than isolated
  points.
- Maximum displacement remains below `6 mm`; topology stays nondegenerate and
  the source object's coordinate digest remains exact.
- A before/after viewport screenshot shows the same broad edit diagnosed by
  the numeric support. Operator success without visible/support evidence fails.

## Artistic continuation if the interface passes

Use the verified interface on another exact disposable copy for one bounded
macro correction to the dominant head/hair mass, retaining full-plush context
and all controlling references. The first correction must target a named
high-impact defect such as the helmet side/rear bulge or hard crown-to-cheek
transition. Render fixed front, side, rear, and both three-quarter views and
obtain implementation-blind review before any detail, materials, rig, or
promotion.

## Stop conditions

- Stop immediately if the live file is dirty or not a disposable task-owned
  copy before sculpting.
- Stop if the MCP cannot access a real `VIEW_3D` context, if brush support
  repeats A71, or if the before/after evidence disagrees.
- Do not compensate with more strokes, remeshes, or a different analytic mesh
  in this attempt. A failed interface gate resets A76.
- A passing operator test is tooling evidence only. It does not count as
  visual goal progress until a separate immutable whole-plush render passes.
