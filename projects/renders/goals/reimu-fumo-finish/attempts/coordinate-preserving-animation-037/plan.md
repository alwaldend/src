# Coordinate-preserving reusable animation copy

Outcome: one reusable collection containing the85 separate visible
character components and the existing rig, with deliberate neutral,
head-yaw, arm-wave and combined actions. Retained033 remains the immutable
editable source. No new visual-likeness pass is claimed by this work.

Evidence identifies18 mesh stacks with Armature before stationary lattices
and44 decorations without bone motion. Uniform unit weights on all41 live
meshes make a final rigid attachment credible. Hook-only attachment would
not give neighboring meshes and curves the same operation order.

Choose an export/rest-baked copy over adding more deformation paths. The
strongest objection is lost Generated texture coordinates and normals,
not geometric capture alone. One nonlinear sleeve coupon already passes
zero world-position drift, nearly identical normals and two-view
coordinate/shader comparisons using a constructive companion field.
That result does not authorize applying the mesh recipe to curves.

1. Test one Generated-shaded beveled curve with its own source-backed
   coordinate path. Preserve all lattice effects, inherited curve texture
   space, full face material assignments and corner normals. Stop on
   coordinate or visible shader mismatch; do not sweep bake recipes.
2. Generalize only established correspondence to41 meshes and44 curves.
   Keep one object per source and one full-weight existing bone. Check
   each topology, evaluated neutral world position, face material indices,
   smoothing, normals and explicit field; reject unsupported cases.
3. Build a separate named candidate with one reusable collection and the
   same rig, retaining sources outside the export collection or in the
   immutable donor file. No destructive edits to retained033.
4. Parent Bow under Head without changing its rest matrix/length/neutral
   placement. Give all parts one final bone transform, with no stationary
   shaping cages after it. Preserve neutral full-character images before
   adding stored actions and testing local-Y head yaw and arm movement.
5. Save a new candidate only with exact source and writer receipts; reopen
   in pinned Blender, render neutral and posed checks, append the one
   collection into a blank file and verify dependencies/actions again.

Amplitudes are test hypotheses, not acceptance thresholds. A posed gap,
clipping or material drift requires a localized causal correction. This
rig implementation must not become a new geometry/style redesign.

Parallel work: curve coupon/helper preparation is independent of root's
head-preview closure and durable-state integration. Root alone saves
canonical model candidates and goal records; workers do not save models.
