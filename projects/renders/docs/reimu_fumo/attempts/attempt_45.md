## Deep process correction

The first module round over-applied the final `8/10` gate to isolated coupons.
That protected the main file but also prevented cumulative whole-model gains.
The revised policy keeps the tracked asset strict while allowing one ignored
working-ladder candidate to accept a reversible module when fixed-view blind
A/B review proves a net complete-model improvement with no critical interface
regression. Only one hypothesis is merged per rung, and the full five-view
absolute gate still controls final promotion.

After two failed representation resets for a tiny coupon, that branch now
stops or expands to the smallest coherent adjacent interface. The ruffle branch
therefore stops after Attempt 50; the active lower-stack module owns the macro
hem/connector relationship while detailed ruffle construction is deferred.
