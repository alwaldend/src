# Reusable Reimu Fumo goal

## Goal

Create a great standalone Reimu Fumo plush model that is recognizably faithful
to the supplied physical references, looks like a sewn plush rather than a
stylized human or assembled primitives, and can be reused and animated in other
Blender projects.

## Status

`in progress` — the existing tracked model is only a migrated failed baseline.

## Follow-on goals — parallel scaffolds, gated asset integration

- Rebuild and polish the Fumo Sisyphus scene around the approved standalone
  asset.
- Make a short Blender animation of the approved Fumo being dropped onto a
  concrete floor.
- Make a short Blender animation of the approved Fumo being dropped into
  water.

These are durable successors, not parallel model branches. Their scene-only
and interface scaffolds may progress in parallel with unmistakable neutral
placeholders. Importing, evaluating, or presenting the changing Fumo as the
character remains blocked until the standalone form and reusable rig
interfaces survive their approval gates, so scaffold work cannot normalize
defects in a rejected plush.
