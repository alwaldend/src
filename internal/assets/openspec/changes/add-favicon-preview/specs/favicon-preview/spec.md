## Purpose

Let contributors inspect how the canonical S8 favicon looks at small sizes
on browser tab backgrounds.

## ADDED Requirements

### Requirement: Standalone favicon showcase

The shared assets project SHALL build a standalone HTML preview from the
canonical S8 SVG.

#### Scenario: Inspect favicon sizes

- **WHEN** a contributor opens the generated preview
- **THEN** it shows the favicon variant at labeled sizes on light and dark
  surfaces and on a white circular backing
